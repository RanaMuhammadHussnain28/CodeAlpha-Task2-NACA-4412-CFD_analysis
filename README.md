# Aircraft Wing CFD & Aerodynamic Flow Analysis

## Overview
This repository contains the complete Computational Fluid Dynamics (CFD) study and 3D flow simulation of an aircraft wing geometry using **SOLIDWORKS Flow Simulation**. 

The goal of this project is to investigate the aerodynamic characteristics, static surface pressure profiles, velocity fields, and boundary layer behaviors of the wing under subsonic airflow conditions.

## Key Features & Simulation Highlights
* **Geometry & Modeling:** 3D CAD aircraft wing designed for aerodynamic performance evaluation.
* **Mesh Generation:** High-resolution computational domain featuring ~796,000 cells with localized refinement along the leading edge, trailing edge, and boundary layers.
* **Physics & Boundary Conditions:** External subsonic flow, no-slip wall conditions, and atmospheric fluid properties.
* **Convergence & Accuracy:** Full solver convergence achieved after 220+ iterations.
* **Data & Visualization:** 
  * Surface pressure distribution plots (identifying stagnation and suction zones).
  * Cross-sectional velocity cut plots.
  * Animated 3D flow trajectories (streamlines & particle behavior).
  * Quantitative aerodynamic force extraction (Lift $F_L$ and Drag $F_D$).
